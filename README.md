# Français

## À propos

Grenoble Roller rassemble la communauté du roller grenoblois autour de randonnées urbaines, de sessions d'initiation et d'événements réguliers. L'association gère aussi une boutique de goodies aux couleurs du club et des adhésions en ligne, pour les adultes comme pour les enfants.

## La plateforme

Toute la vie de l'association est gérée par une plateforme web **open-source** : boutique avec paiement HelloAsso, organisation des randonnées et événements, inscriptions aux initiations avec prêt de rollers, adhésions et panneau d'administration pour les bénévoles.

Le code est public sur [GitHub](https://github.com/Grenoble-roller/Grenoble-Roller-Website), et la plateforme tourne en production sur [grenoble-roller.org](https://grenoble-roller.org/).

## En chiffres

- 90 membres actifs gérés via la plateforme
- 240 inscriptions traitées
- 166 tests automatisés, zéro échec
- Accessibilité WCAG 2.1 AA et conformité RGPD

# English

## About

Grenoble Roller brings together the rollerblading community of Grenoble around urban rides, initiation sessions and regular events. The association also runs a goodies shop with club colours and online memberships, for adults and children alike.

## The platform

The whole association runs on an **open-source** web platform: shop with HelloAsso payments, ride and event organisation, initiation sign-ups with roller rentals, memberships and a volunteer admin panel.

The code is public on [GitHub](https://github.com/Grenoble-roller/Grenoble-Roller-Website), and the platform runs in production at [grenoble-roller.org](https://grenoble-roller.org/).

## By the numbers

- 90 active members managed through the platform
- 240 sign-ups processed
- 166 automated tests, zero failures
- WCAG 2.1 AA accessibility and GDPR compliance
